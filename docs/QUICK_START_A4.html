Magene C606 · c606-oss

Quick start / Краткая инструкция · English + Русский · Wi-Fi / A-GPS / auto zoom

English

1 · Controls

Swipe left/right to change pages. Tap ⚙ for Settings.

Power (0)Press: next page. Hold: power-off dialog; press again to confirm.
Lap (1)Press during a ride: new lap.
Ride (2)Press: start / pause / resume.
Hold: end-ride dialog; confirm to save.

Menus: 2 up · 1 down · 0 select. Select the back arrow to return.

2 · Before your first ride

  • Settings → Language: English / Русский.
  • Profile: set weight, age and training values. Set your Time zone.
  • Take the device outdoors, screen upwards, with a clear view of the sky. Wait for a GPS fix. Satellite count means used / in view.

3 · Ride and save

Tap START RIDE or press 2. Swipe through data pages and the map. Auto pause can stop the timer while stationary. Hold 2 and confirm End to save; see Settings → History.

Settings → Pages changes layouts and fields.

4 · Maps and zoom

The header shows latitude / longitude; N/S/E/W are hemispheres. Without a fix, the map may be blank.

Starts at maximum detail. Auto map zoom zooms out as speed rises. + / − override it for one minute. Disable the option for manual control.

5 · Sensors and A-GPS

Wake the sensor, then Sensors → Add sensor. Choose the result; expect ok and live values. Wheel sets circumference. Supported sensors use ANT+, not Bluetooth-only.

Wi-Fi / GPS time: enter a 2.4 GHz network. Update A-GPS downloads ephemerides; wait for 32 EPO records accepted. Repeat after receiver power loss when needed. Wi-Fi stops afterwards. Sync GPS time sends time only.

6 · Copy files by USB

Settings → System → USB storage. Copy on the computer; safely eject, then tap Reboot.

  • Mapsforge v3–v5 .map (< 2 GiB each) → MAP/
  • .gpx → c606oss/routes/; select under Route.
  • Recorded .fit files: c606oss/
Trouble? Enable System → Debug log before reproducing it; logs are in c606oss/logs/. If frozen, hold all three buttons for a hardware reset. A-GPS still needs satellite reception outdoors.

Русский

1 · Управление

Листайте экраны влево/вправо. Кнопка ⚙ открывает настройки.

Питание (0)Нажать: следующий экран. Удержать: диалог выключения; нажать снова для подтверждения.
Круг (1)Нажать во время поездки: новый круг.
Старт (2)Нажать: старт / пауза / продолжить.
Удержать: завершение; подтвердить сохранение.

Меню: 2 вверх · 1 вниз · 0 выбрать. Для возврата выберите стрелку «назад».

2 · Перед первой поездкой

  • Настройки → Язык: Русский / English.
  • Профиль: задайте вес, возраст и тренировочные параметры. Укажите Часовой пояс.
  • Выйдите под открытое небо, держите экран вверх. Дождитесь позиции GPS. Число спутников: используются / видны.

3 · Запись поездки

Нажмите ПОЕХАЛИ или кнопку 2. Листайте экраны данных и карту. Автопауза останавливает таймер на стоянке. Удержите 2 и подтвердите Завершить. Запись появится в Настройки → История.

Настройки → Экраны: макеты и поля данных.

4 · Карта и масштаб

Вверху — широта / долгота; N/S/E/W — стороны света. Без позиции GPS карта может быть пустой.

Начальный масштаб — максимальное приближение. Автомасштаб карты отдаляет её с ростом скорости. + / − приостанавливают автомасштаб на минуту. Отключите опцию для ручного управления.

5 · Датчики и A-GPS

Разбудите датчик: Датчики → Добавить датчик. Выберите его; проверьте ОК и показания. Колесо — окружность. Нужен ANT+; датчики только с Bluetooth не поддерживаются.

Wi-Fi / время GPS: введите сеть 2,4 ГГц. Обновить A-GPS загружает эфемериды; дождитесь «GPS принял 32 записи EPO». При необходимости повторите после полного выключения. Wi-Fi затем отключится. Обновить время GPS передаёт только время.

6 · Файлы через USB

Настройки → Система → USB-накопитель. Скопируйте файлы, безопасно извлеките диск и нажмите Перезагрузка.

  • Mapsforge v3–v5 .map (< 2 ГиБ каждый) → MAP/
  • .gpx → c606oss/routes/; выбрать в Маршрут.
  • Записи .fit находятся в c606oss/.
Проблема? Включите Система → Журнал отладки; файлы — в c606oss/logs/. При зависании удержите все три кнопки для аппаратного сброса. A-GPS не заменяет приём спутников на улице.
